# 用户使用手册

> 智能科研助理 —— 基于 RAG+Agent 的论文知识库问答系统
> 面向使用者（非开发者）。开发相关内容见 `技术设计文档.md`。

---

## 1. 这个系统能做什么

把论文丢进去，然后用中文直接提问。系统会：

1. 在你的论文库里**检索**出真正相关的原文片段；
2. 让模型**只依据这些片段**回答，并在句中标注引用编号 `[1]`、`[2]`；
3. 展示它的**完整推理过程**（先想了什么、调用了哪个工具、看到了什么）；
4. 如果知识库里确实没有答案，它会**明确告诉你没找到**，而不是编一个。

**它能回答的问题类型**：

| 类型 | 例子 |
|---|---|
| 事实性 | "ViT 用了什么数据集预训练？" |
| 对比性 | "Swin 和 ViT 的注意力机制有什么区别？" |
| 归纳性 | "这个方向常用的评估指标有哪些？" |
| 推理性 | "作者为什么选择移位窗口而不是全局注意力？" |
| 算术 | "3.14 乘 2.56 等于多少？"（不检索，直接算） |

**它不擅长**：扫描件 PDF（图片型，抽不出文字）、需要看图表才能回答的问题、以及知识库里没有的内容。

## 2. 安装

### 2.1 前置条件

- Windows / macOS / Linux
- Python 3.10 或更高（本项目在 Python 3.12 上开发验证）
- 两个 API Key（见下）

### 2.2 安装依赖

```bash
cd RAG+agent的论文知识库问答助手

# 推荐：用项目自带的虚拟环境
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
```

### 2.3 申请 API Key

需要**两个**，都填在 `.env` 里：

| 用途 | 供应商 | 申请地址 | 说明 |
|---|---|---|---|
| 生成答案 | DeepSeek | https://platform.deepseek.com/api_keys | 便宜，充值几元即可 |
| 向量化 + 重排序 | SiliconFlow | https://cloud.siliconflow.cn/account/ak | 注册有免费额度 |

> **为什么需要两家？** DeepSeek 目前不提供 embedding（向量化）接口，所以向量化必须由另一家提供。SiliconFlow 免费额度足够完成课程演示。

### 2.4 配置

```bash
copy .env.example .env          # Windows
# cp .env.example .env          # macOS / Linux
```

用记事本打开 `.env`，把两个 key 填进去：

```dotenv
DEEPSEEK_API_KEY=sk-你的key
SILICONFLOW_API_KEY=sk-你的key
```

保存即可，其它项不用改。

## 3. 启动

```bash
streamlit run streamlit_app.py
```

浏览器会自动打开 `http://localhost:8501`。若没有自动打开，手动访问该地址。

**停止**：回到命令行窗口按 `Ctrl + C`。

## 4. 界面说明

界面分三栏。

### 4.1 左栏 · 文档管理

| 操作 | 说明 |
|---|---|
| **上传** | 点「Browse files」选择文件，支持 **PDF / DOCX / TXT / MD**，可一次选多个 |
| **进度** | 上传后进度条会显示每个文件的解析与向量化进度，大文件需要等一会儿 |
| **文档列表** | 显示已入库的文件名、页数、切分块数、入库时间 |
| **删除** | 点每行右侧的删除按钮，会同时删掉该文档的向量与关键词索引 |
| **刷新** | 重新读取存储目录，用于手动放入 `data/raw/` 的文件 |

**入库要多久？** 大约每 10 页 PDF 需要 5-15 秒，取决于网络与文档长度。同一文件重复上传会被自动跳过，不会重复计费。

### 4.2 中栏 · 对话

在底部输入框提问，回车发送。

- 答案会**逐字流式出现**（打字机效果）；
- 句中的 `[1]`、`[2]` 是引用标记，对应右侧「引用来源」里展开的原文片段；
- 每个引用都标了**文件名 + 页码**，可以自己翻原文核对。

### 4.3 右栏 · 可观测

这一栏是本系统与普通聊天机器人的最大区别——**它把 AI 的思考过程摊开给你看**。

| 区块 | 内容 |
|---|---|
| **推理轨迹** | 展开后是完整的 `Thought（想法）→ Action（调用的工具）→ Observation（工具返回的结果）` 链条。你能看到它先检索了什么、检索到了哪几段、为什么决定停止 |
| **指标** | 本轮消耗的 token 数、各阶段延迟、走的是哪条路径（直接作答 / 检索 / 调用工具）、是否发生了降级 |
| **健康状态** | 顶部横幅。绿色表示两个 API 和本地索引都正常；红色会说明是哪一项出了问题 |

**为什么要看轨迹？** 科研场景下「AI 为什么给出这个答案」和「AI 给出了什么答案」同样重要。如果答案不对，看轨迹通常能立刻定位是**检索没找到**还是**模型理解错了**。

## 5. 常见问题

### Q1. 启动时报错「缺少必填配置: DEEPSEEK_API_KEY」

`.env` 没填 key，或文件不在项目根目录。检查 `.env` 是否存在且 key 已填。

**只想先看看界面长什么样？** 把 `.env` 里这三行改成 mock，即可离线运行（答案内容无意义，但界面和流程完全可用）：

```dotenv
LLM_PROVIDER=mock
EMBEDDING_PROVIDER=mock
RERANK_PROVIDER=mock
```

### Q2. 上传 PDF 后一个问题都答不上来

先看左栏文档列表里的**切分块数**。如果是 `0`，说明这个 PDF 没有可提取的文字——通常是**扫描件**。请先用 OCR 工具（如 Adobe Acrobat、ABBYY，或在线 OCR）转成文本型 PDF 再上传。

### Q3. 回答不准，或者答非所问

按这个顺序排查：

1. **看右栏轨迹的 Observation** —— 检索到的片段本身相关吗？
   - 不相关 → 是检索问题，见第 2、3 条；
   - 相关但答案错 → 是生成问题，见第 4 条。
2. **术语匹配不上**（比如搜「BatchNorm」搜不到）→ 改用 `hybrid` 模式，关键词通道对专有名词更敏感。
3. **片段意思不完整**（一句话被从中间切断）→ 在 `.env` 里调大 `CHUNK_SIZE`（如 `1024`），让它切得粗一些。
4. **模型答偏了** → 把 `TEMPERATURE` 调低到 `0`，减少发挥。

### Q4. 提示「知识库中未找到相关文档」

这是**正常且正确**的行为，不是故障。说明检索确实没找到相关内容。可能原因：

- 文档还没入库完成（看左栏进度条）；
- 问题用词与论文差距太大，换个说法试试；
- 这个内容真的不在你的库里。

系统此时会退到「用模型自身知识回答」，并在答案上方给出⚠️提示——**这段内容没有引用，请自行判断可信度**。

### Q5. 报错 401 / 403

API key 错了或过期了。到对应平台重新生成，更新 `.env`，然后**重启** Streamlit（改 `.env` 不会热加载）。

### Q6. 报错 429 / 余额不足

触发限流或额度用尽。系统会自动重试 3 次（间隔 1、2、4 秒）。若持续失败，检查账户余额。

### Q7. 回答很慢

正常耗时：检索 0.3-0.8 秒，重排序 0.3-0.6 秒，生成 2-8 秒。若明显更慢：

- 网络问题（SiliconFlow 与 DeepSeek 都在国内，一般很快）；
- 对话轮次太多（超过 8 轮会触发摘要压缩，略慢但能防止 token 爆炸）；
- 在 `.env` 里把 `RERANK_TOP_N` 调小。

### Q8. 能同时给多个人用吗？

不能。这是单机单用户的课程项目，没有账号体系。多人同时用会互相覆盖会话。

### Q9. 我的论文数据会被上传到哪里？

- **原文**只存在你本机的 `storage/` 目录，**不会上传**；
- 上传到 DeepSeek 的只有**检索出来的那几段文字 + 你的问题**；
- 上传到 SiliconFlow 的只有**文档分块后的文本**（用于算向量）。

如果论文涉密，请不要使用本系统——这一点在项目背景中已经说明，也是 RAG 架构相对闭源大模型的固有局限。

### Q10. 怎么彻底清空重来？

关闭 Streamlit，删除 `storage/` 目录，重新启动即可。

## 6. 命令行用法（可选）

不用网页也能操作：

```bash
# 批量索引一个目录
python scripts/build_index.py data/raw

# 换分块策略重建（用于对比实验）
python scripts/build_index.py data/raw --strategy recursive --chunk-size 512 --rebuild

# 导出 chunk 清单（编写评测集时要用）
python scripts/build_index.py data/raw --dump-chunks

# 检索效果评测（三档对比）
python scripts/eval_retrieval.py --qa eval/qa_set_demo.jsonl

# Agent 决策评测
python scripts/eval_agent.py --qa eval/qa_set_demo.jsonl

# 全链路自检（不需要真实 key）
python scripts/smoke_test.py
```

## 7. 一页速查

```
装：  pip install -r requirements.txt
配：  .env 里填 DEEPSEEK_API_KEY 和 SILICONFLOW_API_KEY
跑：  streamlit run streamlit_app.py
用：  左栏传论文 → 中栏提问 → 右栏看推理过程
查：  答不准先看右栏的 Observation，判断是检索问题还是生成问题
清：  删掉 storage/ 目录
```
